## Overview
This challenge is a grid landing page for a fictitious non-profit educational organization. The entire work was completed over a couple of hours. It was absolutely satisfying to meet the challenge requirements with precision.

### The challenge

Users should be able to:

- Optimal layout completed for the page and viewable on any device's screen size
- Visible hover and focus states implemented for all interactive elements on the page
- Open and close the navigation menu at any screen size created using input tag as toggle on/off.

## My process
I started with the resources provided to me on the Frontend Mentor platform. The folder contains some design templates, HTML webpage skeleton and style guides. After creating a Github repository for this project, I populated the files and folders on VScode then made increamental commits from VScode directly to Github as I completed subsequent phases in the build process.

The first phase was the complete HTML structure for the webpage using adequate semantic building approach. Then the CSS styling, which I completed using a top-down approach by styling one element/section at a time.

### Built with

- Semantic HTML5 markup
- CSS custom properties
- Flexbox
- CSS Grid
- Mobile-first workflow

### What I learned

I learnt that, using extra large margins to seperate items can lead to incosistencies in the page layout. A better approach would be to embed the elements or items in seperate boxes and then implementin the distance between them using the height and width features of the boxes.

For the first time in my designing process I was also able to intuitely identify cases where I used a global selector for sections with similar layouts therefore removing redundancy within the code to a large extent.
